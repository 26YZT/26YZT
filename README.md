## 主要项目

| 项目 | 方向与主要内容 |
| :--- | :--- |
| [**汽绘 DrawForm**](https://github.com/26YZT/drawform) | **从三维模型，到可继续编辑的工程图。**<br>面向简单单零件，串联 STEP / OCCT 几何、视图与尺寸确认，输出 DXF、SVG、PDF 和 JSON；探索受控文字与图纸建模。 |
| [**云小剧 · YunXiaoJu**](https://github.com/26YZT/yunxiaoju) | **把故事做成可以逐步打磨的 AI 短片。**<br>本地 AI 短片与短剧创作工作台，串联剧本、角色／场景、分镜、参考图、视频片段与后期合成，支持素材版本和多模型接入。 |
| [**Aimy**](https://github.com/26YZT/aimy) | **在电脑前，陪你聊聊今天。**<br>macOS 优先的桌面虚拟陪伴产品，围绕文字／图片、语音、Live2D / VRM 角色与授权看屏，持续打磨日常交流与陪伴体验；基于 Project AIRI 开发。 |
| [**Speed Workbench**](https://github.com/26YZT/speed-workbench) | **从产品想法，到可执行的开发方案。**<br>把需求规划、AI 编码、人工审核和代码迭代组织在同一工作空间，支持模型对比、草稿恢复与预算校验。 |

四个项目都在持续迭代。DrawForm 目前是工程原型，Aimy 处于开发体验阶段；具体能力、使用方式与验证范围见各项目仓库。
