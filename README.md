## 👋 把 AI 产品判断做成可验证的东西

我是 **张岩，一名关注 AI 应用、Agent 与产品研究的 AI 产品经理**。

我习惯从真实问题出发，把复杂的技术判断拆成用户任务、评测方法和可运行的原型。<br />
我不只写需求，也会亲手做 Skill、产品拆解、模型评测流程和可公开交付的工具。<br />

## 🎯 我的优势

- **产品判断 × 动手交付**：能从问题定义走到原型、Skill、评测流程和公开项目，不让需求停在文档里。
- **证据驱动**：先区分页面事实、合理推断和未确认信息，再决定结论能走多远。
- **模型评测底色**：关注评测目标、覆盖矩阵、评分锚点、Bad Case 和可追溯的决策链。
- **复杂内容翻译**：把 Agent、模型和产品机制写成人愿意读、也能继续验证的内容。

## ✍️ 输出方式

我会把研究和实践沉淀成三类公开产物：

1. **可运行的工具**：把重复判断封装成 Skill、模板或轻量产品。
2. **可追溯的分析**：把截图、页面事实、代码和数据整理成结构化报告。
3. **可复用的内容**：把复杂的 AI 产品问题写成读者能看懂、团队能继续讨论的文章。
