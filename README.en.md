## Featured projects

| Project | Focus and scope |
| :--- | :--- |
| [**汽绘 DrawForm**](https://github.com/26YZT/drawform) | **From 3D models to editable engineering drawings.**<br>For simple single parts: STEP / OCCT geometry, view and dimension confirmation, and DXF, SVG, PDF and JSON output. Also explores constrained text- and drawing-based modeling. |
| [**云小剧 · YunXiaoJu**](https://github.com/26YZT/yunxiaoju) | **Turn a story into an AI short film you can refine, stage by stage.**<br>A local short-film and drama creation workspace covering scripts, characters/scenes, storyboards, reference images, video clips and post-production, with asset versions and configurable model providers. |
| [**Aimy**](https://github.com/26YZT/aimy) | **A little company at your computer.**<br>A macOS-first virtual companion combining text/images, voice, Live2D / VRM characters and permission-based screen viewing. Built on Project AIRI and under active development. |
| [**Speed Workbench**](https://github.com/26YZT/speed-workbench) | **From a product idea to an actionable development plan.**<br>A workspace for requirements planning, AI coding, human review and code iteration, with model comparison, draft recovery and budget validation. |

All four projects are under active development. DrawForm is an engineering prototype, and Aimy is a development preview. See each repository for current capabilities, setup and verification scope.
